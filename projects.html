Alzheimer's Disease Classification Using PET Images

Abdoulfatah Abdillahi • Deep Learning Final Project, 2024

Group deep learning project comparing three transfer learning architectures (VGG16, ResNet-50, Inception V3) on ADNI PET scans for 3-class cognitive stage classification (CN, EMCI, AD). Owned ADNI data access and preprocessing; built and tuned the ResNet-50 model while teammates implemented VGG16 and Inception V3.

My Role: Data lead and ResNet-50 implementation — obtained ADNI data access authorization, owned preprocessing and augmentation pipeline, and built the ResNet-50 architecture.
Outcome: Comparative study revealed significant generalization issues — ResNet-50 showed chance-level test accuracy despite 99% validation accuracy; Inception V3 hit 100% validation accuracy, suggesting potential data leakage — highlighting the importance of patient-level splitting in medical imaging.

View Code Slides Report Proposal

Technologies: Python, TensorFlow/Keras, Transfer Learning, ADNI Dataset, ResNet-50
